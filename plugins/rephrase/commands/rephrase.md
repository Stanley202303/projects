# /rephrase

Restate the user's request in accurate and professional software, mathematical, or engineering language, then wait for explicit confirmation before doing any work.

## Preflight

1. Read the user's most recent request carefully.
2. Identify the core objective, explicit constraints, priorities, and expected outputs.
3. Check whether any assumptions, ambiguities, or scope boundaries need to be surfaced before proceeding.

## Plan

1. Rephrase the request precisely without changing its meaning.
2. List the key constraints or priorities that govern the work.
3. Call out open assumptions or points requiring confirmation.
4. Stop and wait for explicit approval or an explicit instruction to proceed.

## Commands

1. Do not run project commands, edit files, implement code, or start analysis beyond clarification.
2. Do not treat implied approval as sufficient.
3. Use accurate professional terminology appropriate to the domain.
4. Keep the restatement concise, but complete enough for scope confirmation.

## Verification

1. Confirm that the rephrased request preserves the user's intent.
2. Confirm that constraints, priorities, and uncertainties are made explicit.
3. Confirm that the response ends in a waiting state rather than advancing into execution.

```text
## Result
- Action: restated the request for alignment
- Status: awaiting confirmation
- Details: objective, constraints, and open assumptions captured
```
